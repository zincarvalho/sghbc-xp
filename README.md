SGHBC-XP – Sistema de Gerenciamento Hospitalar de Baixa Complexidade

Este projeto foi idealizado como atividade prática das cadeiras de Modelo de Melhoria de Projetos / Processo de Melhoria de Processo, ministradas no 5º período do curso de Análise e Desenvolvimento de Sistemas da AESA-CESA, com foco na aplicação de Extreme Programming (XP), Test-Driven Development (TDD), adoção da tecnologias como JAVA com ecossistema Spring.

❗ O projeto foi encerrado (dia 28/05/2025) antes de sua finalização. Esta versão do repositório é mantida apenas para fins didáticos e de registro técnico.

Além dos artefatos produzidos pela equipe, está disponibilizado um *.json exportado do trello com o sprint backlog/wip/test/done.
