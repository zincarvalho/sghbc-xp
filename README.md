# 🏥 SGHBC-XP – Sistema de Gerenciamento Hospitalar de Baixa Complexidade

Este projeto foi idealizado como atividade prática das cadeiras de **Modelo de Melhoria de Projetos** e **Processo de Melhoria de Processo**, ministradas no 5º período do curso de **Análise e Desenvolvimento de Sistemas** da **AESA-CESA**.

O foco foi a aplicação de metodologias ágeis, especialmente:
- **Extreme Programming (XP)**
- **Test-Driven Development (TDD)**
- Adoção de tecnologias como **Java com o ecossistema Spring**/**MYSQL**

❗ **O projeto foi encerrado em 28/05/2025 antes de sua finalização.** Esta versão do repositório é mantida apenas para fins didáticos e de registro técnico.

---

## 📁 Artefatos

Além do código-fonte, este repositório inclui:
- Arquivos auxiliares gerados pela equipe
- Um arquivo `.json` exportado do Trello com o Sprint Backlog (WIP, Test, Done)
